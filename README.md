## ✨ Overview

**BINGO Master** is a digital bingo board which is highly interactive, have visually rich experience designed with a modern **Glassmorphism UI**.

Whether you're:

* Playing solo against intelligent bots 🤖
* Competing offline with friends 📱
* Or hosting real-time online matches 🌐

…the game feels dynamic, smooth, and alive.

---

## 🌟 Key Features

### 🎮 Multiple Game Modes

* **Solo Mode:** Play against up to 3 smart bots
* **Offline Mode (2P):** Play side-by-side
* **Online Multiplayer:** Create rooms and play globally using a 4-digit code

### 💧 Dynamic Theme Engine

Switch between beautifully designed themes:

* *Midnight Dream* 🌙
* *Peach Sunset* 🌇
* *Matcha Latte* 🍵

Each theme includes smooth **liquid ripple transitions**.

### ✨ Rich Animations

Powered by **Anime.js**:

* Interactive tile animations
* Particle click effects
* Winning line highlights
* Subtle ambient UI motion

### 📱 Fully Responsive

A sleek floating-card layout that works seamlessly across:

* Desktop 💻
* Tablets 📱
* Mobile devices 📲

## 🚀 Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/himanshu-rai06/BINGOmaster.git
```

### 2. Navigate to the Project

```bash
cd BINGOmaster
```

Open the folder in your preferred editor (e.g., VS Code).

---

### 3. Setup Firebase (Required for Online Mode)

To enable multiplayer functionality:

1. Go to Firebase Console
2. Create a new project
3. Navigate to **Realtime Database**
4. Create a database (start in *Test Mode*)
5. Go to **Project Settings → Web App**
6. Copy your `firebaseConfig`

Then:

* Open `index.html`
* Locate the `<script type="module">` section
* Replace the existing config with your own

---

### 4. Run the Game

**Quick Method:**

* Open `index.html` directly in your browser

**Recommended Method (VS Code):**

* Install *Live Server* extension
* Right-click `index.html` → **Open with Live Server**

## 🕹️ How to Play

### 1. Board Setup

* Fill the 5×5 grid with numbers (1–25)
* Use:

  * **Random** → auto-generate board
  * **Swap** → rearrange tiles
  * **Undo** → revert last move

---

### 2. Gameplay

* Wait for your turn
* Click a number to mark it
* In online mode, moves sync in real-time

Complete 5 tiles:

* Horizontally
* Vertically
* Diagonally

This lights up letters in **B I N G O**

---

### 3. Winning

Be the first to complete **5 lines**.
The game automatically detects the win and declares the **Bingo Master** 🎉
